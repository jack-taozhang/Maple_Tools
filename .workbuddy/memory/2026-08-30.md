
## QRCoder 引用缺失修复（00:28）
- 现象：编译报"未能找到类型或命名空间名 QRCoder / 未能找到引用的组件 QRCoder"。
- 原因：csproj 已有引用（HintPath=packages\QRCoder.1.4.3\lib\net40\QRCoder.dll，Private=True），但 packages 目录整个不存在（项目被复制/还原后丢失）。
- 修复：用项目根目录自带 nuget.exe 安装：`./nuget.exe install QRCoder -Version 1.4.3 -OutputDirectory packages -NonInteractive`，dll 已就位于 HintPath 精确路径。
- 经验：该项目为老式 packages.config 风格（无 packages.config 文件，直接 csproj HintPath 引用），还原依赖用根目录 nuget.exe install 即可。
